## AdminWebhookService

AdminWebhookService manages channel webhooks. Every RPC requires the
`server.manage` permission, held by the owner and admin roles by default.

<a id="chatto-admin-v1-AdminWebhookService-CreateWebhook"></a>

### CreateWebhook

Creates a webhook against a room and returns its one-time secret URL.
Requires `server.manage`.

```http
POST /api/connect/chatto.admin.v1.AdminWebhookService/CreateWebhook
```

<a id="chatto-admin-v1-CreateWebhookRequest"></a>

#### Input: CreateWebhookRequest

Request to create a webhook against a room.

| Field | Type | Description |
| --- | --- | --- |
| `room_id` | `string` | Required. Room the webhook posts into. |
| `name` | `string` | Required. Webhook name / default author display name. |
| `avatar` | [`chatto.api.v1.ImageUpload`](/reference/connectrpc-api/types/#chatto-api-v1-ImageUpload) | Optional default avatar image, processed into a stored asset. |


<a id="chatto-admin-v1-CreateWebhookResponse"></a>

#### Result: CreateWebhookResponse

Result of creating a webhook, including the one-time secret.

| Field | Type | Description |
| --- | --- | --- |
| `webhook` | [`Webhook`](/reference/connectrpc-api/types/#chatto-admin-v1-Webhook) | The created webhook. |
| `token` | `string` | Raw secret token. Shown once; only its hash is stored server-side. |
| `url` | `string` | Full post URL (base URL + webhook id + token). Shown once. |

### UpdateWebhook

Updates a webhook's name, avatar, or disabled state. Requires
`server.manage`.

```http
POST /api/connect/chatto.admin.v1.AdminWebhookService/UpdateWebhook
```

<a id="chatto-admin-v1-UpdateWebhookRequest"></a>

#### Input: UpdateWebhookRequest

Request to update a webhook's mutable fields. Unset fields are unchanged.

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Required. Webhook to update. |
| `name` | `optional string` | New name, when changing it. |
| `avatar` | [`chatto.api.v1.ImageUpload`](/reference/connectrpc-api/types/#chatto-api-v1-ImageUpload) | New avatar image, when replacing it. |
| `clear_avatar` | `optional bool` | When true, remove the current avatar (mutually exclusive with `avatar`). |
| `disabled` | `optional bool` | New disabled state, when changing it. |

#### Result: UpdateWebhookResponse
