## AdminCustomEmojiService

AdminCustomEmojiService is the administrative surface for managing the server
custom emoji catalog. Every RPC requires the `server.manage` permission,
which is held by the owner and admin roles.

<a id="chatto-admin-v1-AdminCustomEmojiService-CreateCustomEmoji"></a>

### CreateCustomEmoji

Creates a custom emoji from an uploaded image. Requires `server.manage`.

```http
POST /api/connect/chatto.admin.v1.AdminCustomEmojiService/CreateCustomEmoji
```

<a id="chatto-admin-v1-CreateCustomEmojiRequest"></a>

#### Input: CreateCustomEmojiRequest

Request to create a new custom emoji from an uploaded image.

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Required. Shortcode name, unique across the server catalog and distinct from the built-in gemoji vocabulary. Lowercase letters, digits, and underscores are recommended; validated further by the server. |
| `image` | [`chatto.api.v1.ImageUpload`](/reference/connectrpc-api/types/#chatto-api-v1-ImageUpload) | Required. The source image to process into the emoji (resized to a small square WebP; animated GIFs are preserved as animated WebP). |


<a id="chatto-admin-v1-CreateCustomEmojiResponse"></a>

#### Result: CreateCustomEmojiResponse

Result of creating a custom emoji.

| Field | Type | Description |
| --- | --- | --- |
| `emoji` | [`chatto.api.v1.CustomEmoji`](/reference/connectrpc-api/types/#chatto-api-v1-CustomEmoji) | The newly created custom emoji. |
