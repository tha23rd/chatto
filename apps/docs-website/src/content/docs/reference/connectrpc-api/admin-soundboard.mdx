## AdminSoundboardService

AdminSoundboardService is the administrative surface for managing the server
soundboard catalog. Mutating RPCs require the `soundboard.manage` permission
or the broader `server.manage` permission; both are held by the owner and
admin roles by default, and `soundboard.manage` can be granted on its own to
a narrower role.

<a id="chatto-admin-v1-AdminSoundboardService-CreateSound"></a>

### CreateSound

Creates a sound from an uploaded audio clip. Requires `soundboard.manage`
or `server.manage`.

```http
POST /api/connect/chatto.admin.v1.AdminSoundboardService/CreateSound
```

<a id="chatto-admin-v1-CreateSoundRequest"></a>

#### Input: CreateSoundRequest

Request to create a new soundboard sound from an uploaded audio clip.

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Required. Display name for the sound, 1-64 characters. |
| `audio` | [`chatto.api.v1.AudioUpload`](/reference/connectrpc-api/types/#chatto-api-v1-AudioUpload) | Required. The source audio clip. The server validates format, size, and stores the clip as-is; clients decode it for playback. |
| `emoji` | `string` | Optional emoji icon (unicode or custom emoji shortcode) for the button. |
| `volume` | `float` | Optional default playback volume in [0, 1]. Defaults to 1 when zero/unset. |
