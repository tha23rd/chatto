## CustomEmojiService

CustomEmojiService exposes the read side of the server custom emoji catalog.
It is available to any authenticated user for the emoji picker and for
resolving custom reaction shortcodes to images. Management (create/delete)
lives in the administrative chatto.admin.v1.CustomEmojiService.

<a id="chatto-api-v1-CustomEmojiService-ListCustomEmojis"></a>

### ListCustomEmojis

Lists all custom emojis defined on the server. Available to any
authenticated user.

```http
POST /api/connect/chatto.api.v1.CustomEmojiService/ListCustomEmojis
```

Request to list all custom emojis defined on the server.
