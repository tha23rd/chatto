## SoundboardService

SoundboardService exposes the read side of the server soundboard catalog. It
is available to any authenticated user to render the soundboard panel in the
voice call UI. Management (create/delete) lives in the administrative
chatto.admin.v1.AdminSoundboardService.

<a id="chatto-api-v1-SoundboardService-ListSounds"></a>

### ListSounds

Lists all soundboard sounds defined on the server. Available to any
authenticated user.

```http
POST /api/connect/chatto.api.v1.SoundboardService/ListSounds
```

<a id="chatto-api-v1-ListSoundsRequest"></a>

#### Input: ListSoundsRequest

Request to list all soundboard sounds defined on the server.
